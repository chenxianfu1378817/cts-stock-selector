# CTS 短线决策台

基于同花顺问财 OpenAPI 的本地 A 股选股网页，面向 1 万元账户的 2–5 日短线交易。

## 功能

- 盘中筛选“现在可买”的标的，主动排除已经大涨、位置过高或风险收益比不足的股票。
- 收盘筛选下一交易日观察股。
- 自动核对市场环境、板块强度、量价位置、财务与事件风险。
- 自动计算 100 股整数仓位、最低佣金、印花税、T+1 与跳空缓冲。
- 每只候选输出推荐理由、买入上限、止损、目标、持有、卖出和取消条件。

## 本机使用

双击 `start-local.command`。程序会从 `~/.config/iwencai/api_key` 读取本机密钥并打开
`http://localhost:3000`。密钥不会写入网页、日志或 Git 仓库。

也可以在终端中设置 `IWENCAI_API_KEY` 后运行：

```bash
npm install
npm run dev
```

## 安全边界

本项目不包含任何 API Key。不要把 `.env`、`.dev.vars` 或凭据文件提交到 Git。
选股结果用于执行和验证个人交易系统，不构成收益承诺。
